# Day 2 - HTTP and JSON

## Objective

Understand HTTP communication, JSON data, GET and POST
requests, path parameters, query parameters, and status codes.

## Concepts Learned

- HTTP
- HTTP Request
- HTTP Response
- JSON
- GET
- POST
- Path Parameters
- Query Parameters
- Request Headers
- Response Headers
- Request Body
- Status Codes

## HTTP Request Structure

A request can contain:

- HTTP Method
- URL
- Headers
- Query Parameters
- Request Body

Example:

GET /users/5

## HTTP Response Structure

A response contains:

- Status Code
- Headers
- Response Body

Example:

200 OK

## GET Request

GET is generally used to retrieve information.

Example:

```text
